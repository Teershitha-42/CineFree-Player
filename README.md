#  CineFree Player

**CineFree Player** is a responsive movie and series discovery platform developed using HTML, CSS, JavaScript, and Bootstrap.

It allows users to explore different categories of movies and series, including Popular Movies, Telugu Movies, Anime Movies, Anime Series, Telugu Full Movies, and Korean & Asian Series.

##  Features

- Browse popular movies.
- Explore Telugu movies.
- Discover anime movies and series.
- Watch supported Telugu movies through YouTube embeds.
- Explore Korean and Asian series.
- View movie and anime information dynamically.
- Easy navigation between different categories.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- TMDB API
- Jikan API
- YouTube Embed

## 🔗 APIs Used

- **TMDB API:** Fetches popular movie details and Telugu movie information.
- **Jikan API:** Fetches anime and episode information.
- **YouTube:** Embeds supported videos and playlists.

##  How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Explore the different movie and series categories.

##  Note

TMDB and Jikan APIs provide content information and metadata, not full movie video files. Video playback uses supported YouTube embeds.
